The Facing Yourself project was a Japanese manga Styled Comic created for the capstone class in my final year of the DePaul University.


Presentation Copies of the Comic




First Test Animation for Animation Direction

The project lasted 20 weeks, the length of two quarters at DePaul. During the first half it started as an animation centered project.
The premise of the project started off as a set of animations exploring different emotions. After the initial meetings with the critique groups we formed in the class, I realized that, while having some substance behind it, the idea was ultimately a little narrow in scope.
So that lead to the first pivot.



The second go around was going to be another animation, and this version featured a more fantasy theme for the project.
This time featuring a pixelated aesthetic with RPG style dialogue boxes and possibly voice acting. This was decided with a project I did the prior semester, The Meeting (Jake Ver.). In which, I used a 3D model and stylized version of my character I've had since childhood. To fill out the rest of the cast I asked my friends if I could use their characters.


Half-Way Presentation for the Project



The central plot was about facing down an evil reflection of the main character, with the cast growing and processing their past during the journey.
